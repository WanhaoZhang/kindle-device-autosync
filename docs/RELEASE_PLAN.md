# PW2 复现流程完善

目标是让公开源码、预发布包和使用说明对应，并减少首次安装及批量新增书籍的 USB 往返。

当前已确认原生采集、在线 TLS、单书 915 秒自动上传及延迟回读。历史跨日批次和长期性能仍未完成验收。

本轮工作包括把候选对应作为独立的追加记录导入设备，保留原配置绑定和已有账本。设备仅在原生会话与唯一 sidecar 计数身份一致后启用新对应。新增书籍的准备和导入集中为一轮，未读候选先保留到实际识别。首次安装仍保留探针、OTA 重启检查和真实试传确认。

验证覆盖候选路径、身份隔离、已有映射不可替换、重复导入、没有原生证据时等待、已有授权持续有效，以及源码打包、ARM ELF、SHA256 和发布包重新下载。单台实机观察与离线回归分别记录。

## 本轮验证结果

- Python 98 项、C 25 项、Rust worker 98 项离线回归通过。
- 新书对应的账号绑定、路径限制、不可替换旧目标、重复导入和原生证据等待均覆盖。
- 已发布的 915 秒自动到账来自旧队列程序。0.2.0 的追加对应及合并新安装路线仍待真机验收。
- 完整 ZIP 通过公开 Git 提交生成 Mac 助手源码，设备包要求源提交相同且全文件 SHA256 匹配。发布后重新下载校验。
