# Preview 0.2.0

完整 ZIP 包含 Mac 配置助手源码、PW2 ARM 程序、KUAL 菜单、许可证、来源提交和 SHA256。运行助手需要 Python 3.11+；普通安装使用预编译设备包。

## 操作变化

- 首次离线安装、自检、导入、防护和重启集中到一个 KUAL 动作。
- 设备已启用后，网页可一次选择多本候选，导出后在 KUAL 一次导入。未读书籍等待真实原生身份，日后正常阅读即可继续。
- 新书追加不改基础配置绑定和原授权。重复导入相同对应保持幂等，修改目标或身份歧义会被拒绝。
- 原试传统计延迟时，再点同一个确认入口只做只读核验，不重复提交时长。可在同一次拔线期间等待。
- 只有明确收到回执且归属完整的旧批次才允许隔离。其同书或同日继续等待，书籍和日期都独立的记录可继续同步。

## 复现范围

已实测原生后台采集、在线 TLS、同日短试传和一次 915 秒后台提交及延迟到账。该书累计和目标日期均精确增加，原位置相同。跨日旧批次仍有回执成功但未入账的案例。

本版本新增的候选追加和合并首装流程通过离线回归，尚未在全新设备上完整验收。正式性能与完整协议矩阵待完成。默认只采集，实验启用仍要求真实设备自检和实际到账试传。

已有安装的普通组件升级会使旧程序授权失效，需重新核验。针对已知历史二进制的授权接续脚本有严格来源限制，不能当作所有旧版本的通用升级器。

## 构建发行包

从本次 Git 提交克隆，在干净工作区按设备构建说明产生候选包，然后执行：

```sh
python3 tools/release.py --package device/build/out/package --version 0.2.0 --out dist/0.2.0
```

脚本核对候选与 Git 来源相同、完整 SHA256 索引及全部包文件，然后只打包已提交的 Mac/source 文件。用户运行数据留在本机私有目录。

操作入口见 [快速安装](QUICKSTART.md)，逐阶段失败和恢复见 [完整复现](PW2_REPRODUCTION.md)。
