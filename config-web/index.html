Kindle 自动同步 · 书籍对应

这是 Kindle 端项目的配置助手。它提供专用扫码、旧实例交接、准确书籍对应和 USB 配置导出；没有 Mac 阅读日志导入或时长上传功能。

这里可以一次选好几本新书，核对微信读书版本并保存到本机。候选清单部署到 Kindle 后才会用于自动同步。

给新书选择微信读书版本

先选 Kindle 里的书，再搜索并核对微信读书的作者和版本。保存后的候选对应留在本机，页面会列出待部署清单。

这台 Kindle 的对应清单

安装 Preview 0.2.0 或更新版本后，导出并安全弹出，在 KUAL 点 Import selected books + export status。未读候选会等到首次原生阅读并取得精确计数身份后启用。可一次导入多本。

首次安装与高级配置

1. 选择安装方式

用过网页版时，填写保存真实账号及账本的旧项目目录。不要选择新的空克隆。交接会封锁该旧实例写入，保留未核验记录。

3. 交接并设置书籍对应


迁移用户可载入旧项目中已经确认的对应。全新用户可先保存空数组、导出并在 Kindle 导入配置；新增阅读后，在 KUAL 导出脱敏状态，再接回这里读取精确本地书籍 ID。

4. 导出配置
USB/FAT 暂存不具备私有文件权限保护。请在自己的电脑上导出，安全弹出后及时在 KUAL 选择 Import USB configuration；成功导入会删除暂存凭据。空对应仅用于首次采集识别新书。修改书籍对应会使旧验收绑定失效。


设备导出的状态
